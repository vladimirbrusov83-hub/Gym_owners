# Build with Claude for Gym Owners

A free course teaching gym owners how to build AI tools using Claude — no coding required.

**Live site:** [vladimirbrusov83-hub/Gym_owners](https://github.com/vladimirbrusov83-hub/Gym_owners)

---

## What this is

A practical, self-paced course for gym owners who want to use Claude to solve real operational problems — member intake, difficult conversations, communication, and hiring. Every module gives you a complete, ready-to-use prompt you can paste into Claude today.

No software to install. No developers. No ongoing subscriptions beyond Claude itself.

---

## Course structure

| Module | Title | What you build |
|--------|-------|----------------|
| 1 | Start Here | Claude account setup + your Gym Profile Block |
| 2 | Member Intake Assistant | A Claude Project your front desk uses to onboard new members |
| 3 | Difficult Conversations | Scripts for cancellations, price increases, warnings, reviews, staff feedback |
| 4 | Member Communication Library | Prompts for newsletters, check-ins, win-back campaigns, review responses |
| ★ | Bonus — Hiring & Staff | Job postings, interview questions, onboarding plans, offer/rejection messages |

## Design

- **Colors:** Anthropic palette — warm cream background, terracotta orange accent (`#D97B54`), dark warm text
- **Fonts:** Inter (body), JetBrains Mono (prompt blocks)
- **Responsive:** Mobile hamburger menu, readable on all screen sizes

---

## Running locally

No build step. Open any HTML file directly in a browser:

```bash
open index.html
```

Or serve locally:

```bash
python3 -m http.server 8080
# then open http://localhost:8080
```
